MoE Mix Grid Results

Three full-length Qwen3.6-35B-A3B detectors trained with the same recipe (84,000 rows, 3 epochs, 1e-4 cosine, LoRA rank 128 / expert rank 16), differing only in training mix. Every model is scored on identical rows at stage-2 epoch 2.

Updated Oct 7, 11:25 PM PDT · one seed per run · T2.1 mix run trained on the H200 (final-moe), mixes A and B on Space A100s

Verdict

  1. Mix B is out. It is last or tied for last on every set, and its scores sit so low that its paper threshold is 0.17 (the others: 0.40–0.43), so it flags 2.6–3.9% of human-control sentences on clean v2, the humanizer set and light polish.
  2. The T2.1 mix and mix A are close, and each wins different sets. The T2.1 mix is best on paper-edit small edits (0.63 vs 0.54), long AI sections (0.98 vs 0.97), the Fable humanizer set (0.96 vs 0.94) and standalone rewrites (0.67 vs 0.55). Mix A is best on clean v2 (0.92 vs 0.89, +3.0 points [2.3, 3.6]) and ties on strict held-out small edits (0.61 vs 0.62).
  3. Mix A is better calibrated. At the paper threshold it flags 1.3% of clean-v2 human sentences and 1.8% on strict held-out, against 1.7% and 2.7% for the T2.1 mix, so mix A’s deployed false-positive rate is closer to the 1% target.
  4. Recommendation: the T2.1 mix if paper-edit and standalone detection matter most; mix A if calibration on new writers and sources matters most. Most gaps are 1–3 points on one seed each, so a second seed of both should decide it.

What went into each mix

Share of rows per stage-2 epoch (24,000 for the T2.1 mix, 72,000 distinct rows for mixes A and B, which run one pass over three different files). All mixes were screened against every held-out list when built.

Caveats

  1. One seed each. Bracketed intervals resample papers, so they cover evaluation-set noise, not seed noise.
  2. Validation loss selected epoch 1 for the T2.1 mix and mix B and epoch 0 for mix A; every box uses epoch 2 so the three are compared at the same point.
  3. Clean v2 excludes every paper T2.1 may have seen. The T2.1 mix run was scored on the full v2 file on the H200; its rows here are restricted to the same clean subset.
