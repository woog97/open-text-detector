Architecture
Frozen eligible seed manifest -> topic workers -> durable brief queue -> writer workers -> CPU validation -> immutable result shards/private publication.
Every stage carries seed ID, passage hash, parent family, partition, protocol/model/config identity. Topic extractor alone receives original text. Writer payload is reconstructed from an allowlist: topic, document type/genre, language, target words. Never send original text/title implicitly. One independent API request per synthetic document. Keep current passage-length task unless document scope is explicitly changed.
